# `index.html` -> `Next.js` 迁移账本

> 目的：把离线原型里仍有价值、但尚未回灌到 `Next.js` 主应用的能力记成显式账本，避免两条线路继续隐性分叉。

> 当前规则：新增产品能力默认落在 `Next.js` 主线。`index.html` 只继续承担离线演示、交互试验和对照参考；未记入本账本的离线原型增量默认不继续扩展。

## 1. 唯一依据

- 产品主线：`app/` + `components/` + `lib/`
- 离线参考线：`index.html`
- 当前主工作台组件：`/Users/jilanfang/ai-quality/components/workspace.tsx`
- 当前离线原型参考实现：`/Users/jilanfang/ai-quality/index.html`

## 2. 迁移判断规则

- `立即迁移`：应进入当前 P0 / P1，直接影响演示、试用、信任感或主链路一致性
- `稍后迁移`：有价值，但不该阻塞当前 MVP 加固
- `仅保留在离线原型`：保留在离线演示线，当前不迁回产品主线
- `跳过`：当前不建议迁移
