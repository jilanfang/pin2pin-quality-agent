# Superpowers 产物说明

这里存放 agent 工作流生成的计划稿和设计稿。

它们的用途是：

- 保留当时的计划过程
- 回看某轮决策为什么这样做
- 给后续复盘提供上下文

它们不负责：

- 维护当前 backlog
- 维护当前产品边界
- 代表当前实现已经落地

使用规则：

- 要看长期任务，回到 [`../mvp-hardening-checklist.md`](../mvp-hardening-checklist.md)
- 要看正式运行边界，回到 [`../deployment-and-demo.md`](../deployment-and-demo.md)
- 要看当前文档入口，回到 [`../README.md`](../README.md)
